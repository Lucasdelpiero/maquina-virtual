Code segment
Data segment : Para variables globales o variables definidas como static
ES: Extra segment o mas bien conocido como heap
SS: Stack Segment: Zona memoria dedicada a la pila
KS: Constant Segment
PS: Param segment, parametros que vienen por la linea de comandos especificamente se guardan aqui.
